# Talos Linux v1.13.10 & Kubernetes v1.35.8 Wipe-and-Rebuild Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cleanly wipe and reprovision the Camp Colt Talos Kubernetes cluster (`camp-colt-k8s`) directly to Talos Linux v1.13.10 and Kubernetes v1.35.8, upgrading and re-attaching the ASUS Ascent GX10 GPU accelerator node (`colt-gpu-01`).

**Architecture:** Safely detach `colt-gpu-01` from the legacy cluster and upgrade its Ubuntu APT kubelet/kubeadm stack to v1.35. Wipe the Talos VMs (`colt-control-01` and `colt-worker-01`) via declarative Terraform/Talos reset, reprovision with Talos v1.13.10 ISO and machine configs, bootstrap Kubernetes directly at v1.35.8, re-join `colt-gpu-01` with its Kubeprism local proxy, restore ingress/storage services, and confirm Flux CD prerequisites (`flux check --pre`).

**Tech Stack:** Talos Linux v1.13.10, Kubernetes v1.35.8, `talosctl`, `kubectl`, Terraform (Proxmox provider), Ubuntu 24.04.4 LTS (Grace Blackwell GB10), Ingress-NGINX, Rancher Local Path Provisioner.

### Task 1: Detach & Upgrade GX10 GPU Accelerator Node (`colt-gpu-01`)

**Files:**

- Modify: `/etc/apt/sources.list.d/kubernetes.list` on `colt-gpu-01` (`10.82.0.3`)

**Interfaces:**

- Consumes: SSH CA authentication to `colt-gpu-01`, `colt-kubeconfig`
- Produces: `colt-gpu-01` cleanly detached, reset, and updated to `kubelet`/`kubeadm` v1.35.x

- [ ] **Step 1: Drain and delete colt-gpu-01 from old cluster**

```bash
kubectl --kubeconfig colt-kubeconfig drain colt-gpu-01 --delete-emptydir-data --force --ignore-daemonsets || true
kubectl --kubeconfig colt-kubeconfig delete node colt-gpu-01 || true
```

- [ ] **Step 2: Reset kubelet and CNI state on colt-gpu-01**

```bash
ssh -F ssh_config colt-gpu-01 "sudo kubeadm reset -f && sudo rm -rf /etc/cni/net.d/* /var/lib/kubelet/* /etc/kubernetes/kubelet.conf /etc/kubernetes/pki/*"
ssh -F ssh_config colt-gpu-01 "sudo systemctl stop kubelet"
```

- [ ] **Step 3: Upgrade APT repository and packages to v1.35 on colt-gpu-01**

```bash
ssh -F ssh_config colt-gpu-01 "echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.35/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list"
ssh -F ssh_config colt-gpu-01 "sudo apt-get update && sudo apt-get install -y --allow-change-held-packages kubelet kubeadm kubectl && sudo apt-mark hold kubelet kubeadm kubectl"
ssh -F ssh_config colt-gpu-01 "kubelet --version && kubeadm version"
```

### Task 3: Wipe & Re-provision Talos VMs

**Files:**

- Regenerate: `colt-talosconfig`
- Regenerate: `colt-kubeconfig`

**Interfaces:**

- Consumes: Proxmox API (`colt-cp-01` @ `10.82.0.2`), Terraform
- Produces: Fresh Talos v1.13.10 VMs (`colt-control-01`, `colt-worker-01`) bootstrapped with K8s v1.35.8

- [ ] **Step 1: Reset existing Talos VMs**

```bash
talosctl --talosconfig colt-talosconfig -n 10.82.0.13 reset --graceful=false --reboot --system-labels-to-wipe STATE,EPHEMERAL || true
talosctl --talosconfig colt-talosconfig -n 10.82.0.10 reset --graceful=false --reboot --system-labels-to-wipe STATE,EPHEMERAL || true
```

- [ ] **Step 2: Apply Terraform to re-download ISO and recreate / reconfigure VMs**

```bash

```

- [ ] **Step 3: Bootstrap fresh cluster and extract configs**

```bash

talosctl --talosconfig colt-talosconfig config node 10.82.0.10
talosctl --talosconfig colt-talosconfig -n 10.82.0.10 bootstrap
talosctl --talosconfig colt-talosconfig -n 10.82.0.10 kubeconfig ../colt-kubeconfig --force
```

- [ ] **Step 4: Verify control plane and worker node status**

```bash

```

### Task 4: Re-attach ASUS Ascent GX10 (`colt-gpu-01`) to Fresh Cluster

**Files:**

- Consumes: `colt-kubeconfig`
- Systemd: `kubeprism-proxy.service` on `colt-gpu-01`

**Interfaces:**

- Consumes: Fresh cluster join token/CSR
- Produces: `colt-gpu-01` joined and reporting `Ready` with `v1.35.x`

- [ ] **Step 1: Ensure kubeprism-proxy is pointing to fresh control plane**

```bash
ssh -F ssh_config colt-gpu-01 "sudo systemctl restart kubeprism-proxy.service && sudo systemctl status kubeprism-proxy.service --no-pager"
```

- [ ] **Step 2: Generate join token and execute kubeadm join on colt-gpu-01**

```bash
JOIN_CMD=$(talosctl --talosconfig colt-talosconfig -n 10.82.0.10 kubeconfig - | kubeadm token create --print-join-command 2>/dev/null || true)
# Join colt-gpu-01 targeting the local Kubeprism endpoint (127.0.0.1:7445)
ssh -F ssh_config colt-gpu-01 "sudo kubeadm join 127.0.0.1:7445 --token <TOKEN> --discovery-token-unsafe-skip-ca-verification"
```

- [ ] **Step 3: Label node and verify Ready status**

```bash
kubectl --kubeconfig colt-kubeconfig label node colt-gpu-01 accelerator=nvidia-gb10 nvidia.com/gpu.present=true --overwrite
kubectl --kubeconfig colt-kubeconfig get nodes -o wide
```
