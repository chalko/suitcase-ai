# Talos Linux v1.14.0 (QEMU Guest Agent) & Kubernetes v1.36.4 Deployment Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cleanly wipe and reprovision the Camp Colt Kubernetes cluster (`camp-colt-k8s`) with Talos Linux v1.14.0 containing the built-in `qemu-guest-agent` system extension and Kubernetes v1.36.4, enabling Proxmox guest visibility, and re-attaching the ASUS Ascent GX10 GPU accelerator node (`colt-gpu-01`).

**Architecture:** Use Sidero Labs Image Factory (`factory.talos.dev`) to download an official Talos v1.14.0 ISO pre-baked with `siderolabs/qemu-guest-agent` (schematic `ce4c980550dd2ab1b17bbf2b08801c7eb59418eafe8f279833297925d67c7515`). Enable `agent { enabled = true, trim = true }` in Proxmox VM definitions. Apply Talos v1.14.0 declarative machine configs via Terraform, bootstrap Kubernetes at v1.36.4, re-attach `colt-gpu-01` via local Kubeprism proxy, redeploy ingress and local storage, and verify `flux check --pre`.

**Tech Stack:** Talos Linux v1.14.0 (Image Factory custom schematic with `siderolabs/qemu-guest-agent`), Kubernetes v1.36.4, Proxmox VE 9.2 QEMU Agent, `talosctl` v1.14.0, Terraform (`bpg/proxmox`), Ubuntu 24.04.4 LTS (GB10).

**Spec:** [plans/phase_1_k8s_networking_and_ingress.md](file:///home/luna-mayor-agent/luna/rigs/suitcase-ai/plans/phase_1_k8s_networking_and_ingress.md), [AGENTS.md](file:///home/luna-mayor-agent/luna/rigs/suitcase-ai/AGENTS.md).
